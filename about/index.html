About Us

Protecting Minecraft Since 2026

Built by competitive Minecraft developers and network administrators with a focus on TPS stability and zero false positives.

Our Core Mission

Competitive Minecraft servers have long struggled with a dilemma: aggressive anticheats that lag the server and false-ban legitimate PvP combos, or passive anticheats that let modern ghost clients bypass detection.

We created Icelite to solve both sides of this equation. By intercepting raw Netty packets and evaluating deterministic physics models, Icelite catches subtle combat modifications while preserving 20.0 TPS.

Server-Side Purity

100% server-side operation. Players never need to install third-party clients, launchers, or background daemons.

Zero False Bans

Extensively calibrated across high-ping environments, lag spikes, and complex vanilla mechanics to guarantee fairness.

Modern Architecture

Native multi-threading, Folia thread-safety, Netty channel pipelines, and asynchronous webhook dispatching.

Engineering Principles

Every single check in Icelite is governed by four strict standards:

  1. Deterministic Verification: A player is only flagged when actions mathematically violate Minecraft movement and combat limits.
  2. Zero Main-Thread Blocking: Heavy heuristics, Discord webhooks, and database logging are strictly offloaded from the server tick thread.
  3. Granular Configuration: Server operators retain complete control over check thresholds, cancel actions, freeze triggers, and per-world rules.
  4. Instant Updates: Rapid patches ensure detection stays ahead of evolving ghost clients and combat bypasses.
