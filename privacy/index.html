Privacy & Security

Privacy Policy

Last updated: January 2026. How Icelite respects player privacy and manages telemetry.

1. Player Privacy Standard

Icelite Anticheat is strictly a server-side detection suite. We do not operate on player computers, scan personal drives, access background desktop processes, or gather client-side hardware identifiers.

2. Data Collection & Telemetry

When cloud heuristics and violation logs are enabled by the server administrator, the only data transmitted consists of:

  • In-game player UUID and player name.
  • In-game packet timing deltas (coordinates, rotation angles, click timings, tick timestamps).
  • Server IP address and port for license verification.

3. Data Retention & Security

All heuristic data transmitted to Icelite cloud nodes is encrypted in transit using TLS 1.3. Replay logs and tick buffers older than 30 days are purged automatically.

4. Server Owner Control

Server owners have complete liberty to disable cloud heuristics in config.yml and operate in fully localized offline mode if desired.

5. Contact Data Privacy Officer

For questions regarding data processing or data deletion requests, contact our privacy team at primary@icelite.top.
